# Projeto de Atendimento em C

## Descrição
Este projeto implementa um sistema de atendimento utilizando estruturas de dados como filas, listas, pilhas e árvores binárias. O sistema permite cadastrar, consultar, atualizar e remover pacientes, bem como gerenciar a ordem de atendimento e registrar as operações em arquivos.

## Funcionalidades
O projeto está dividido em cinco áreas principais:

### Cadastro de Pacientes
- Cadastrar novos pacientes
- Consultar informações de um paciente
- Mostrar a lista de pacientes cadastrados
- Atualizar dados de um paciente
- Remover um paciente do sistema

### Atendimento
- Enfileirar paciente para atendimento
- Desenfileirar paciente após atendimento
- Mostrar a fila de atendimento

### Pesquisa de Pacientes
- Pesquisar pacientes por ano do registro
- Pesquisar pacientes por mês do registro
- Pesquisar pacientes por dia do registro
- Pesquisar pacientes por idade

### Desfazer Operação
- Desfazer o último enfileiramento ou desenfileiramento

### Carregar Arquivo
- Carregar dados de pacientes a partir de um arquivo

###  Salvar Arquivo
- Salvar os dados do programa em um arquivo

## Estruturas de Dados Utilizadas
- **Lista**: Utilizada para armazenar e gerenciar os pacientes cadastrados.
- **Fila**: Usada para controlar a ordem de atendimento dos pacientes.
- **Pilha**: Implementada para desfazer a última operação de enfileiramento ou desenfileiramento.
- **Árvore Binária**: Utilizada para pesquisas rápidas de pacientes.
